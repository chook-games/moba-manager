# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/). Versioning: [SemVer](https://semver.org/).

## [0.7.0] — Phase 5: Distribution

### Added
- **Privacy policy** page (`privacy.html`, EN + EL) — no data collected.
- **Store assets** in `store/`: 1024 icon, 1024×500 feature graphic, bilingual listing copy.
- **Real gameplay screenshots** (`store/screenshots/`) generated by `tests/screenshots.mjs`.
- **TWA/Bubblewrap templates** in `twa/` for shipping to Google Play, plus a Digital Asset Links
  template and full publish checklist.
- Manifest enriched with `screenshots`, `id` and `prefer_related_applications`.
- `.gitignore` now excludes Android signing keys / build outputs.

## [0.6.0] — Phase 2: Content

### Added
- **6 new champions** (18 total): Volleystorm, Emberlord, Gravemaw, Bloodmoon, Lifewarden, Ironclad.
- New ultimate **Aegis Wall** (`OVERSHIELD`) — shields every nearby ally.
- **4 new items** (12 total): Devourer, Stasis Hourglass, Ghostblade, Juggernaut Plate.
- **4th mode: Sudden Death** — structures at 60% HP for short, explosive matches.
- **Per-mode environment tint** (scene background/fog colour).

## [0.5.0] — Phase 3: Missions

### Added
- **Daily quests** — 4 rotating objectives each day (seeded by date), progress tracked per day,
  claim Gold rewards.
- **Achievements** — 8 lifetime milestones with one-time Gold rewards.
- **Daily login reward** — escalating Gold streak (Day 1–7+), shown on the home screen.
- **Missions screen** (from the home menu) with progress bars and claim buttons.
- New profile data: lifetime counters + daily state, all with save migration.

## [0.4.0] — Phase 4: UX / i18n / accessibility

### Added
- **English + Greek localization** — full UI translation with a Language switch in Settings
  (auto-detects Greek browsers on first run). All screens, help, tutorial, modes and rewards
  are translated.
- **Reduce motion** setting — disables camera shake, screen flashes and animations.
- **Next minion-wave timer** in the HUD (for modes with minions).
- Landscape-phone layout tweaks and larger tap targets.

## [0.3.0] — Phase 1: Game feel

### Added
- **Audio** — generated WebAudio SFX (hits, kills, ultimates, structures, victory/defeat, UI).
  Sound on/off + volume in Settings (persisted). Unlocks on first user gesture.
- **Vibration / haptics** on hits, kills, ultimates, structures and match end (Android).
- **Feedback / "juice"** — kill feed, screen flash, camera shake, 3D death bursts and
  projectile impact sparks.
- **First-match interactive tutorial** — auto-advances as you select a hero, give an order,
  fire an ultimate and buy an item. Replayable from Settings.
- **Help modal** explaining orders and target priorities (❔ button in the Tactics panel).

## [0.2.0] — Phase 0: Stability & QA

### Added
- Continuous integration: GitHub Actions runs syntax checks + smoke tests on every push/PR.
  A non-blocking headless-Chrome e2e job verifies the full game flow.
- `tests/check-syntax.mjs` — `node --check` across the whole codebase.
- `tests/smoke.mjs` — imports the full module graph and validates game logic,
  data integrity and **save migration** from old/corrupt saves.
- `tests/browser.mjs` — portable (Win/mac/Linux) DevTools-Protocol e2e test: home → mode →
  squad → game, hero selection, pause/resume, resize, console-error detection.
- `tests/serve.mjs` — tiny local static server (`npm run serve`).
- `package.json` with test/serve scripts.
- `APP_VERSION` constant (shown in Settings).
- `CHANGELOG.md`.

## [0.1.1] — Selection fix

### Fixed
- Hero selection lag: switching between champions now reacts instantly.
  - Squad dock selection uses `pointerdown` (no tap delay).
  - Squad dock no longer rebuilds its DOM every refresh (incremental updates).
  - 3D selection uses large invisible hitboxes and picks the closest champion to the camera.

## [0.1.0] — Gameplay simplification & desktop

### Added
- Responsive desktop layout (wider shell, more grid columns); camera starts zoomed out.

### Changed
- Orders reduced to `Farm / Push / Defend / Retreat` (removed `Gank` and `Fight`).
- Support escort chooser moved into the Tactics tab (shows only when a Support is selected);
  removed the separate Support tab.

## [0.0.0] — Initial release

### Added
- 3D MOBA-manager gameplay (Three.js), 12 champions, item shop, tactics, meta progression,
  unlocks, 3 modes (ARAM / Blitz / Titan Siege), PWA (offline + installable), mobile + desktop.
